# Generate Image

## לפני שמתחילים

- **מפתח** — הסקריפט מוצא אותו לבד: משתנה הסביבה `GEMINI_API_KEY`, או
  הקובץ `.business-os/gemini-api-key` בתיקיית הפרויקט (או בתיקיית הבית).
  המייסד שם אותו שם, מחוץ לשיחה.
  - האם יש מפתח — `--status` אומר מאיפה נמצא, בלי להציג אותו. חסר או
    פגום — הסקריפט עוצר ואומר, וזה חסם בראש הדיווח.
  - הקובץ **לעולם** לא נכנס ל-git: הסקריפט כותב `.gitignore` בתיקייה,
    ומתריע (⚠️, חסם בראש הדיווח) אם הקובץ כבר במעקב.
  - לעולם לא קוראים את קובץ המפתח, לא מדפיסים את המפתח, לא כותבים אותו
    לשום מקום ולא מבקשים אותו בצ'אט. שומר הסף חוסם את הדרכים הגלויות —
    קריאת הקובץ, הדפסת משתני הסביבה, חיפוש מפתחות, ומחרוזת שנראית כמו מפתח
    בפקודה, בסוכן או בשירות חיצוני — אבל לא כל דרך. הכלל עצמו מחייב.
- **עלות** — מנוהלת אצל המייסד ב-Google Cloud, לא כאן. בכל זאת חוסכים:
  `flash` לטיוטות, `pro` לגרסה שנבחרה, ולא 20 וריאציות כשצריך 3.

## יצירה

ל-`pro` ול-4K — timeout של 300000 בכלי Bash.

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/generate_image.py --prompt "..." --model flash --size 1K --aspect 1:1 --out design/assets/<slug>/<name>.png
```

- `--model`: `flash` לטיוטות, `pro` לגרסה סופית, `lite` לסקיצות (1K בלבד).
- `--aspect`: 1:1, 4:5, 5:4, 3:4, 4:3, 2:3, 3:2, 9:16, 16:9, 21:9.
- `--size`: 1K, 2K, 4K (`lite` — 1K בלבד).
- `--out` — ‎.png, ‎.jpg או ‎.webp, נתיב יחסי לתיקיית ה-venture. אם המודל
  מחזיר כמה תמונות, הנוספות נשמרות כ-`<name>-2.png` וכו'.
- `--ref <קובץ>` — תמונת ייחוס או תמונה לעריכה; אפשר כמה פעמים (עד 14).
  עריכה = `--ref` לתמונה הקיימת + תיאור השינוי ב-`--prompt`.

## ב-Cowork בענן

תיקיית הפרויקט לא נמצאת בסביבת הענן. מגיעים אליה רק עם כלי ה-device,
ומה שנוצר בענן נמחק בסוף השיחה אם לא הוחזר לתיקייה.

1. **מפתח — פעם אחת בתחילת השיחה.** `--status` אומר שחסר מפתח? מעלים
   את קובץ המפתח עם `mcp__remote-devices__device_stage_files`, `paths` =
   הנתיב המלא של `.business-os/gemini-api-key` בתוך התיקייה המחוברת (את
   שורש התיקייה נותן `get_device_info`, בשדה `connectedFolders`). הכלי
   מחזיר רק נתיב וגודל, לא את התוכן. אחר כך מריצים **את אותה פקודת
   `--status` בדיוק** — בלי `cd`, בלי להעתיק את הקובץ ובלי להוסיף נתיב;
   הסקריפט מוצא את הקובץ שהועלה לבד. צריך לומר "נמצא".
   - **לא קוראים את הקובץ שהועלה**, לא מעבירים את הנתיב שלו לאף כלי ולא
     מריצים פקודות בתיקייה שלו — מערכת ההרשאות של Cowork חוסמת את זה
     כחיפוש מפתחות, ובצדק.
   - העותק שהועלה נמחק לבד בסוף השיחה. לא מוחקים אותו ולא שואלים עליו
     את המייסד.
2. **תמונת ייחוס מהפרויקט** — מעלים אותה קודם עם `device_stage_files`,
   ומעבירים ל-`--ref` את ה-`stagedPath` שחזר.
3. **יצירה** — `--out /mnt/user-data/outputs/design/assets/<slug>/<name>.png`.
4. **שמירה בתיקיית הפרויקט — חובה.** `mcp__remote-devices__device_commit_files`
   עם `stagedPath` = הקובץ ב-`/mnt/user-data/outputs/...`, ו-`devicePath` =
   הנתיב המלא של `design/assets/<slug>/<name>.png` בתוך התיקייה המחוברת.
   אותו דבר ל-`record.md`. בדיווח — הנתיב בתיקיית הפרויקט, לא בענן.
5. **"אין תשובה מלאה מ-Google"** — הגישה ל-Google חסומה בסביבה. חסם בראש
   הדיווח: המייסד בודק את הגדרות הרשת ב-Claude. לא עוקפים דרך
   `device_bash`.

## עברית בתוך תמונה

- טקסט קצר, בדיוק כמו שייכתב, ואמירה מפורשת שזה עברית מימין לשמאל:
  `a headline in Hebrew, right-to-left, that reads exactly: שלום עולם`.
- לטקסט בעברית עדיף `pro`.
- בודקים את התוצאה אות אחר אות (`Read` מציג את התמונה). יש שיבוש —
  מוסיפים את הטקסט כשכבה ב-Canva במקום.
