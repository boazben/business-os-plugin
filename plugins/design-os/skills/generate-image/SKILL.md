# Generate Image

## לפני שמתחילים

- **מפתח** — משתנה הסביבה `GEMINI_API_KEY`, שהמייסד הגדיר. חסר — הסקריפט
  עוצר ואומר. לעולם לא מדפיסים את המפתח, לא כותבים אותו לקובץ ולא
  מבקשים אותו בצ'אט.
- **איפה המונה** — במחשב של המייסד: `~/.business-os/`. ב-Cowork, שמוחק את
  תיקיית הבית בכל שיחה: `.business-os/` בתוך תיקיית ה-venture המחוברת.
  אין תיקייה כזו — הסקריפט לא ייצור תמונה בתשלום (⛔), כי לא יוכל לזכור
  את ההוצאה.
- **תקציב** — `image-budget.json` באותה תיקייה, למשל
  `{"monthly_budget_usd": 10}`. אין קובץ — 10$. רק המייסד משנה אותו,
  מחוץ לשיחה; שומר סף חוסם שינוי מתוך שיחה.

## יצירה

פקודה אחת, בדיוק בצורה הזו — בלי `cd` לפני, בלי `&&`, בלי משתנה סביבה
לפני `python3`, ובלי התווים `; & | < > `` ` `` בתוך הטקסט (שומר סף חוסם
כל צורה אחרת). ל-`pro` ול-4K — timeout של 300000 בכלי Bash.

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/generate_image.py --prompt "..." --model flash --size 1K --aspect 1:1 --out design/assets/<slug>/<name>.png
```

- `--model`: `flash` לטיוטות (~0.07$ ב-1K), `pro` לגרסה סופית (~0.13$
  ב-1K/2K, ~0.24$ ב-4K), `lite` לסקיצות זולות (~0.03$, 1K בלבד).
- `--aspect`: 1:1, 4:5, 5:4, 3:4, 4:3, 2:3, 3:2, 9:16, 16:9, 21:9.
- `--size`: 1K, 2K, 4K (`lite` — 1K בלבד).
- `--out` — ‎.png, ‎.jpg או ‎.webp, נתיב יחסי לתיקיית ה-venture. אם המודל
  מחזיר כמה תמונות, הנוספות נשמרות כ-`<name>-2.png` וכו', וכל אחת נספרת.
- `--ref <קובץ>` — תמונת ייחוס או תמונה לעריכה; אפשר כמה פעמים (עד 14).
  עריכה = `--ref` לתמונה הקיימת + תיאור השינוי ב-`--prompt`.

## סטטוס תקציב

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/generate_image.py --status
```

## שורת התקציב — חובה להעביר

בסוף כל ריצה הסקריפט מדפיס שורת תקציב:

- `תקציב תמונות: ...` — רגיל.
- `⚠️ ...` — עברנו 90% או 100%. **מעתיקים מילה במילה לראש הדיווח.**
- `⛔ ...` (קוד יציאה 3) — 130%, או שאין איפה לזכור הוצאות: לא נוצרה
  תמונה. **חסם בראש הדיווח.** לא מנסים דרך אחרת; שומר סף חוסם עקיפה.

## עברית בתוך תמונה

- טקסט קצר, בדיוק כמו שייכתב, ואמירה מפורשת שזה עברית מימין לשמאל:
  `a headline in Hebrew, right-to-left, that reads exactly: שלום עולם`.
- לטקסט בעברית עדיף `pro`.
- בודקים את התוצאה אות אחר אות (`Read` מציג את התמונה). יש שיבוש —
  מוסיפים את הטקסט כשכבה ב-Canva במקום.

## מה המונה סופר ומה לא

- כל ריצה נספרת לפי הערכה **לפני** הקריאה ל-Google, ומתוקנת אחריה לפי
  מה שחזר: תמונות, טוקני קלט, וטוקני חשיבה וטקסט — לפי המחירון הרשמי
  (נבדק 2026-09-15). ריצה שנקטעה או לא קיבלה תשובה נשארת ספורה. זו
  **הערכה**; החשבונית ב-Google Cloud היא הקובעת.
- לא סופר: Veo, כלי AI של Canva ו-Figma, ושימוש במפתח מחוץ ל-business-os.
- חודש = חודש קלנדרי (UTC). ב-Cowork המונה הוא לכל תיקיית venture בנפרד.
